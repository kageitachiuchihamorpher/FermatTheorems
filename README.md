# FermatTheorems
This repository is designed to create practical applications for mathematical and physical theorems such as The Legendary Fermat's Last Theorem. With this repository, all complex analyses will simplified to ranged and spanned integer domains (x-values).

The Qualos program is for two practical purposes, the first of which being a distance/inertia calculation for the universe with each i value spanning a billion years. The second purpose is determine how much the lottery is able to accumulate, if one were to assume that each dollar "goes the distance".

The Satoshi Hat application is designed to create a unified processor core that can exceed a quantum processing computer... in due time.
